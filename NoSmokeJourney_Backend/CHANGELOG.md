# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added
- Initial release of No Smoke Journey API
- N-Tier Architecture implementation
- JWT-based authentication and authorization
- User management with role-based access control
- Smoker profile management
- Nicotine Addiction Test (Fagerström model)
- Cancer Risk Assessment tool
- Progress Tracker with milestones
- Doctor directory with reviews and ratings
- Medical centers with location-based search
- Seminar registration system
- Recovery stories with moderation
- Educational content management
- Health milestones tracking
- Interactive quit timeline
- Swagger API documentation
- Docker support
- Postman collection for API testing

### Features
- **Authentication**: JWT tokens, refresh tokens, password hashing with BCrypt
- **User Management**: Registration, login, profile management, password change
- **Health Tools**: Addiction test, cancer risk assessment, progress tracking
- **Educational Content**: Articles, videos, infographics with body organ categorization
- **Community**: Recovery stories, seminar registrations
- **Doctor Directory**: Search, filter, reviews, ratings

### Technical
- .NET 8.0
- Entity Framework Core 8.0
- SQL Server
- AutoMapper
- JWT Authentication
- Repository Pattern with Unit of Work
- Generic Repository implementation
- Comprehensive DTOs for all entities
- API versioning support
- Pagination support
- CORS configuration
